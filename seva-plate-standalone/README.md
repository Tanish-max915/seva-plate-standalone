# Seva Plate — standalone project

A standalone React + TypeScript + Vite app styled with Tailwind CSS. It includes the Seva Plate landing/browse experience and local sample listings. Meal offers, orders, pickups, and donations are illustrative only; this demo does not process transactions or arrange donations.

## Requirements

- Node.js 20.19 or newer (Node.js 24 recommended)
- npm (included with Node.js)

## Install and run

From this folder, run:

```bash
npm install
npm run dev
```

Open the local URL shown by Vite (normally http://localhost:5173).

## Other commands

```bash
npm run typecheck
npm run build
npm run preview
```

The production build is written to `dist/`. The preview command serves that build locally on port 4173.
